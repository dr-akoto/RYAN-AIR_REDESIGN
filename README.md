# RYAN AIR - Airline Booking Website

A modern, responsive airline booking website for Ryan Air with a complete flight search, booking, and confirmation flow.

## Features

- **Flight Search**: Search for flights with flexible options
  - Round trip or one-way flights
  - Multiple passenger selection
  - Different travel classes (Economy, Premium, Business, First)
  - Date selection with validation

- **Flight Results**: Browse available flights
  - Dynamic flight generation
  - Price comparison
  - Flight duration and stop information
  - Easy selection and booking

- **Booking System**: Complete your reservation
  - Passenger information form
  - Payment details (mock payment system)
  - Booking summary with pricing breakdown
  - Terms and conditions acceptance

- **Confirmation**: Get your booking details
  - Unique booking reference number
  - Complete flight and passenger information
  - Email confirmation notification

- **Responsive Design**: Works seamlessly on all devices
  - Mobile-friendly navigation
  - Adaptive layouts for tablets and phones
  - Touch-optimized interface

## Pages

1. **index.html** - Homepage with flight search form and popular destinations
2. **results.html** - Flight search results page
3. **booking.html** - Passenger and payment information form
4. **confirmation.html** - Booking confirmation page

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript**: Interactive functionality and form handling
- **Responsive Design**: Mobile-first approach

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Start searching for flights!

## How to Use

1. **Search for Flights**:
   - Enter your departure and destination cities
   - Select travel dates
   - Choose number of passengers and class
   - Click "Search Flights"

2. **Select a Flight**:
   - Browse available flights
   - Compare prices and times
   - Click "Select" on your preferred flight

3. **Complete Booking**:
   - Fill in passenger information
   - Enter payment details (mock payment - no real transactions)
   - Accept terms and conditions
   - Click "Complete Booking"

4. **Get Confirmation**:
   - Receive your unique booking reference
   - View complete booking details
   - Confirmation email sent to provided address
